# 🧪 Projeto em Destaque

# 🏢 LVM Corporate Lab

Laboratório criado para simular uma infraestrutura corporativa utilizando Windows Server 2025, máquinas clientes e ferramentas de segurança.

O objetivo do projeto é compreender como ambientes empresariais funcionam na prática, desde gerenciamento de identidades até monitoramento e resposta a eventos.

## Arquitetura do ambiente

### 🖥️ Servidor

- Windows Server 2025
- Active Directory Domain Services (AD DS)
- DNS
- Organizational Units (OUs)
- Usuários e Grupos
- RBAC (Role-Based Access Control)
- Compartilhamento de arquivos SMB
- Group Policy (GPO)

### 💻 Endpoints Windows

- Computadores ingressados no domínio
- Aplicação de políticas corporativas
- Controle de usuários
- Monitoramento de eventos

### 🔐 Segurança

- Wazuh SIEM
- Sysmon
- Coleta e análise de logs
- Monitoramento de atividades nos endpoints
